# Polish glossary of Voicedot terms

Use these terms when speaking Polish. The product is in Polish for a person
whose dashboard is set to Polish: name what is on screen with the Polish label
from this table, for example: kliknij „Przekaż agentowi”. Give the English label
in quotes only to someone whose dashboard is in English.

| English (product) | Polski |
|---|---|
| feedback, comment | uwaga, komentarz |
| pin | pinezka (pin) |
| thread | wątek |
| conversation | rozmowa |
| dashboard | panel |
| inbox | skrzynka |
| widget | widget |
| reviewer, commenter | osoba przeglądająca, autor uwagi |
| team member | członek zespołu |
| owner | właściciel |
| project | projekt |
| address (exact HTTPS origin) | adres (dokładny adres HTTPS z portem) |
| saved page view, snapshot | zapisany widok strony |
| resolved | rozwiązane |
| open | otwarte |
| close a pin | zamknąć pinezkę (ukryć ją na stronie) |
| reply in the thread | odpowiedź w wątku |
| internal note | notatka wewnętrzna |
| review round | runda sprawdzania |
| Checked | Sprawdzone |
| Needs fix | Do poprawy |
| To check | Do sprawdzenia |
| Direct (address mode) | Roboczy |
| Team (address mode) | Zespołowy |
| Public (address mode) | Publiczny |
| Hand to an agent | Przekaż agentowi |
